Priyanka Vergadia introduces Compute Engine as virtual machines (VMs) running in Google's data centers. The 2020 primer focuses on choosing a machine to fit an existing application's resource needs and keeping it running during host maintenance [00:00–01:43](https://www.youtube.com/watch?v=IuK4gQeHRcI&t=0s).

### Key Points Covered

- **Match resources to the workload**: The examples pair general-purpose machines with web servers, memory-optimized machines with in-memory databases, and GPUs with intensive computation such as machine learning [00:00–00:48](https://www.youtube.com/watch?v=IuK4gQeHRcI&t=0s).
- **Move between hosts without rebooting**: Live migration is presented as keeping applications running during maintenance. Separately, right-sizing recommendations suggest changing the machine type to better fit measured usage [00:48–01:43](https://www.youtube.com/watch?v=IuK4gQeHRcI&t=48s).
- **Lower-cost options have different conditions**: The 2020 overview includes discounts tied to usage or commitments and describes Preemptible VMs as short-term instances for batch jobs and fault-tolerant workloads. These are historical product and pricing terms, not a current quote [00:48–01:43](https://www.youtube.com/watch?v=IuK4gQeHRcI&t=48s).
