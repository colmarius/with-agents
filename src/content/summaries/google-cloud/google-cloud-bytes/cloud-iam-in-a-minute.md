Cloud Identity and Access Management (IAM) controls who can access Google Cloud resources. This 2021 primer explains how centrally managed policies can give users the access they need without granting broad access to everything [00:00–00:54](https://www.youtube.com/watch?v=zd5d9Vv1ZFE&t=0s).

### Key Points Covered

- **Manage access across the organization**: Resource Manager organizes resources into organizations, folders, and projects. Used with IAM, it lets administrators change policies across that hierarchy, with a unified policy view and auditing [00:00–00:54](https://www.youtube.com/watch?v=zd5d9Vv1ZFE&t=0s).
- **Find overly broad permissions**: IAM Recommender is presented as detecting overly permissive access and helping administrators reduce it. The primer describes assistance with access decisions, not an automatic replacement for them [00:54–01:38](https://www.youtube.com/watch?v=zd5d9Vv1ZFE&t=54s).
