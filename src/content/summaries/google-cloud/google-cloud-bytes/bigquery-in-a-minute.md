The source names neither its presenter nor an affiliation. This 2020 primer places BigQuery in the managed analytical data-warehouse category.

### Key Points Covered

- **The warehouse supports batch and streaming ingestion**: BigQuery is presented as ingesting, storing, and querying datasets while Google manages the underlying infrastructure [00:00:00].
- **SQL is exposed through several interfaces**: The primer describes a standard SQL dialect available through the console, command-line tools, APIs, and client libraries, with business-intelligence integrations for visualization [00:00:00].
- **The pricing vocabulary is a 2020 snapshot**: Storage, streaming inserts, and query processing are separated, with per-query and flat-rate query options described at the time [00:00:55].

Use this as historical analytical-warehouse orientation, not schema, performance, or cost guidance. Validate current ingestion, SQL behavior, storage models, editions and reservations, locations, quotas, limits, and pricing in current documentation.
