BigQuery is a managed data warehouse: a place to collect large datasets and analyze them with SQL while Google operates the underlying infrastructure. This 2020 primer follows the path from loading data to querying and visualizing it [00:00–00:55](https://www.youtube.com/watch?v=CFw4peH2UwU&t=0s).

### Key Points Covered

- **Load a batch or stream data as it arrives**: The primer presents both upload paths, with streaming intended to make incoming data available for real-time analysis [00:00–00:55](https://www.youtube.com/watch?v=CFw4peH2UwU&t=0s).
- **SQL is exposed through several interfaces**: The primer describes a standard SQL dialect available through the console, command-line tools, APIs, and client libraries, with business-intelligence integrations for visualization [00:00](https://www.youtube.com/watch?v=CFw4peH2UwU&t=0s).
- **The pricing vocabulary is a 2020 snapshot**: Storage, streaming inserts, and query processing are separated, with per-query and flat-rate query options described at the time [00:55](https://www.youtube.com/watch?v=CFw4peH2UwU&t=55s).
