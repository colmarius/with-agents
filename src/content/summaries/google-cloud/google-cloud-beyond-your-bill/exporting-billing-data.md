Mark Mirchandani presents billing export as a foundation for custom cost analysis: retain detailed records, query allocation dimensions, and build stakeholder views. The 2019 export schema, IAM, BigQuery, Data Studio, and console specifics require confirmation in current documentation.

### Key Points Covered

- Mirchandani recommends enabling detailed export early because the historical feature did not reconstruct all earlier detail. [00:00–00:47](https://www.youtube.com/watch?v=ZyMO9XabUUM&t=0s)
- The walkthrough exports to BigQuery and notes that storing and analyzing cost data can itself cost money. [00:47–01:36](https://www.youtube.com/watch?v=ZyMO9XabUUM&t=47s)
- A dedicated project or dataset can isolate the cost-management data plane. [01:36](https://www.youtube.com/watch?v=ZyMO9XabUUM&t=96s)
- Location, project, and label dimensions support allocation and trend queries. [02:26](https://www.youtube.com/watch?v=ZyMO9XabUUM&t=146s)
- The episode connects BigQuery to reusable and custom Data Studio dashboards. [03:14–04:06](https://www.youtube.com/watch?v=ZyMO9XabUUM&t=194s)
