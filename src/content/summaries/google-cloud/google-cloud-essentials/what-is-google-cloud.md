Ryan, whose affiliation is unstated, introduces cloud computing and shows how applications can combine managed compute, storage, database, and machine-learning services. [00:00:00]-[00:05:16]

### Key Points Covered

- Provider-operated infrastructure lets teams run applications and data workloads without provisioning every physical system themselves. [00:00:00]-[00:01:03]
- Managed services can absorb scaling, sharding, backup, performance, and infrastructure-security work. [00:01:03]-[00:02:05]
- Compute Engine, Cloud Run, and App Engine illustrate different hosting models, while Cloud Storage, Cloud SQL, and Firestore illustrate object, relational, and document data models. [00:02:05]-[00:03:08]
- Prebuilt AI APIs and Vertex AI represent different levels of machine-learning abstraction. [00:03:08]-[00:04:11]
