### Key Points Covered

- Containers package an application with its dependencies, but the runtime determines how much infrastructure a team operates. [00:00–01:04](https://www.youtube.com/watch?v=jh0fPT-AWwM&t=0s)
- GKE provides managed Kubernetes orchestration, scheduling, scaling, health, upgrades, and cluster options. [00:00–02:08](https://www.youtube.com/watch?v=jh0fPT-AWwM&t=0s)
- Cloud Run provides a managed, scale-to-zero model for stateless containers, while Compute Engine supports containers on familiar virtual machines. [02:08–04:16](https://www.youtube.com/watch?v=jh0fPT-AWwM&t=128s)
- The delivery path joins image storage, access control, automation, vulnerability information, and runtime deployment. [04:16–05:19](https://www.youtube.com/watch?v=jh0fPT-AWwM&t=256s)
