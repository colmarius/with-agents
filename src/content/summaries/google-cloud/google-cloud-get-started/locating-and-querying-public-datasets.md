This walkthrough finds an American Community Survey public dataset, inspects it, and runs a sample BigQuery query. [00:00:01]-[00:03:10]

### Key Points Covered

- Public datasets offer reusable records, such as census and weather data, that can be queried or joined without first importing a private copy. [00:00:01]-[00:01:03]
- The listing exposes description, update metadata, tables, schema, size, row count, preview data, and sample queries. [00:01:03]-[00:02:06]
- The example runs a prebuilt King County rent query and presents the BigQuery sandbox as a bounded starting path. [00:02:06]-[00:03:10]
- The episode points to Data Studio as a no-code visualization path. [00:02:06]-[00:03:10]

Treat the 2020 Marketplace screens and pricing language as historical. Data Studio is now named Looker Studio; use current live Google Cloud documentation for BigQuery procedures and visualization workflows.
