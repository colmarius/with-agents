This quickstart creates a blank standard Persistent Disk, attaches it to a VM, then prepares it from an SSH session. [00:00:00]-[00:02:11]

### Key Points Covered

- The console example creates a 500 GB disk and attaches it to an existing VM as an additional disk. [00:00:00]-[00:01:03]
- The guest operating system must discover and format the device before it can store files. [00:01:03]-[00:02:11]
- The example creates a mount directory, mounts the disk with discard enabled, and changes directory permissions. [00:01:03]-[00:02:11]

Treat the 2018 device names, commands, screens, and procedures as historical; use current live Google Cloud and guest-OS documentation before formatting or mounting storage.
