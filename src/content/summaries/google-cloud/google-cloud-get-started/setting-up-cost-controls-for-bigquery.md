This walkthrough introduces custom daily BigQuery query quotas at project and per-user scope as one cost-control technique. [00:00:01]-[00:01:06]

### Key Points Covered

- A project quota limits aggregate query data processed in the project, while a user quota applies separately to each user or service account. [00:00:01]-[00:01:06]
- When both quotas apply, usage counts against both and the stricter limit governs the query. [00:00:01]-[00:01:06]
- The example enters limits in tebibytes and explains that exceeding a daily limit produces an error. [00:01:06]

Treat the 2020 interface, units, and submission procedure as historical; use current live Google Cloud BigQuery documentation to choose and verify cost controls.
