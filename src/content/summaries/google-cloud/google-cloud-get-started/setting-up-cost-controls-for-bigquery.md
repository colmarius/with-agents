BigQuery can process large amounts of data in a single query. This walkthrough shows how daily quotas limit the amount of query data processed, helping control runaway queries rather than setting a cap on every kind of BigQuery charge. [00:01–01:06](https://www.youtube.com/watch?v=3Z1SzQsYnH8&t=1s)

### Key Points Covered

- A project quota limits aggregate query data processed in the project, while a user quota applies separately to each user or service account. [00:01–01:06](https://www.youtube.com/watch?v=3Z1SzQsYnH8&t=1s)
- When both quotas apply, usage counts against both and the stricter limit governs the query. [00:01–01:06](https://www.youtube.com/watch?v=3Z1SzQsYnH8&t=1s)
- The example enters limits in tebibytes and explains that exceeding a daily limit produces an error. [01:06](https://www.youtube.com/watch?v=3Z1SzQsYnH8&t=66s)
