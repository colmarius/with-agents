This item-level application-access walkthrough deploys an App Engine sample and places Identity-Aware Proxy in front of it. [00:00:01]-[00:01:06]

### Key Points Covered

- The presenter deploys a sample with the gcloud CLI and first confirms that the unprotected app responds. [00:00:01]-[00:01:06]
- A person or group receives the IAP-secured Web App User role. [00:00:01]-[00:01:06]
- After IAP is enabled, the authorized account can enter while another account receives an access-denied response. [00:01:06]

Treat the 2019 screens and activation flow as historical and this item as focused app-access orientation, not a complete security design; use current live Google Cloud IAP and App Engine documentation for procedures.
