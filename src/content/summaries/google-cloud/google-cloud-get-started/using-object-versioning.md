This walkthrough demonstrates Cloud Storage Object Versioning with legacy `gsutil` commands. [00:00:01]-[00:01:05]

### Key Points Covered

- With Object Versioning enabled, overwriting or deleting a live object creates or retains a noncurrent generation. [00:00:01]-[00:01:05]
- The example enables, disables, and checks versioning on a bucket. [00:00:01]-[00:01:05]
- Older versions are identified and addressed by generation number, while the current version remains the default visible object. [00:01:05]

Treat the 2020 `gsutil` procedure as historical and use current live Google Cloud documentation. Object Versioning is distinct from soft delete; do not conflate their retention, restoration, lifecycle, or cost behavior.
