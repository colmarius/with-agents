This walkthrough contrasts creating auto mode and custom mode VPC networks in the 2018 Cloud console. [00:00:00]-[00:01:05]

### Key Points Covered

- Auto mode uses a predefined subnet mode, while custom mode requires each regional subnet and address range to be specified. [00:00:00]-[00:01:05]
- The custom example places subnets in three regions, showing that one VPC network can contain regional subnets. [00:00:00]-[00:01:05]
- The demonstration stops after network creation and does not configure firewall policy, routes, or connectivity. [00:01:05]

Treat the 2018 screens and procedures as historical; use current live Google Cloud documentation for network design and implementation.
