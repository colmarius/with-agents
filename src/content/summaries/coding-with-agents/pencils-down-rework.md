REWORK host Kimberly Rhodes speaks with 37signals co-founders Jason Fried and David Heinemeier Hansson about finishing Basecamp 5. The episode turns their AI-accelerated design process into a practical distinction between fast exploration and durable production software.

### Key Points Covered

- **Agents extend design exploration**: Designers can produce working features much earlier, but scale, database load, and architectural fit still require experienced review [00:03:50]-[00:05:57].
- **A working prototype can become the specification**: Designers iterate with agents until the interaction is right; programmers then turn that result into production code instead of assuming the generated implementation should ship [00:05:57]-[00:09:50].
- **Speed does not create durability**: Fried says established software still needs human diligence over edge cases, interactions, and details [00:10:52]-[00:11:55].
- **Taste becomes scarcer than implementation**: Cheap feature generation raises the value of deciding what belongs and maintaining a cohesive product [00:12:42]-[00:13:38].
- **The final quarter can dominate the work**: Their CLI demo arrived quickly, but consistency, ergonomics, and finishing made the path from roughly 75% to production disproportionately difficult [00:13:38]-[00:15:22].

The percentage framing is a practitioner estimate; the episode provides no measured delivery or defect comparison.
