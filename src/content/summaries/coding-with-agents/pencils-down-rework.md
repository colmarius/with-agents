REWORK host Kimberly Rhodes speaks with 37signals co-founders Jason Fried and David Heinemeier Hansson about finishing Basecamp 5. The episode turns their AI-accelerated design process into a practical distinction between fast exploration and durable production software.

### Key Points Covered

- **Agents extend design exploration**: Heinemeier Hansson says designers can now produce working features with less help from programmers, but scale, database load, and architectural fit still require experienced review [03:50–05:57](https://www.youtube.com/watch?v=otvGsbeOdfc&t=230s).
- **A working prototype can become the specification**: In a method Heinemeier Hansson heard about at Shopify, designers iterate with agents until the interaction is right; programmers then turn that result into production code instead of assuming the generated implementation should ship [05:57–09:50](https://www.youtube.com/watch?v=otvGsbeOdfc&t=357s).
- **Speed does not create durability**: Fried says established software still needs human diligence over edge cases, interactions, and details [10:52–11:55](https://www.youtube.com/watch?v=otvGsbeOdfc&t=652s).
- **Choosing what to ship becomes the scarce skill**: Heinemeier Hansson says cheaper development makes taste, product direction, and cohesiveness more valuable. With 100 features you could ship, deciding which few should go out becomes the expensive part [12:42–13:38](https://www.youtube.com/watch?v=otvGsbeOdfc&t=762s).
- **The final quarter can dominate the work**: The first version of their command-line interface for agents arrived quickly, but consistency, ergonomics, and finishing made the path from roughly 75% to production disproportionately difficult. That percentage is their estimate, not a measured division of the work [13:38–15:22](https://www.youtube.com/watch?v=otvGsbeOdfc&t=818s).
