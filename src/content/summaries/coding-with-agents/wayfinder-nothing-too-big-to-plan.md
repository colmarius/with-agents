Matt Pocock presents Wayfinder, a planning skill for work with too many unresolved decisions for one agent session. It stores questions and their dependencies in an issue tracker. Each new session tackles an answerable question; its result can unblock the next one. Pocock calls this a map, with a “frontier” of available work and “fog” covering decisions that are still blocked.

### Key Points Covered

- **Plan uncertainty, not only implementation tasks**: An initial question-and-answer session establishes the destination, then identifies decisions that need research, prototyping, further discussion, or real-world action [02:02–04:09](https://www.youtube.com/watch?v=F3lL98Pj90o&t=122s).
- **Persist the route in an issue tracker**: Child tickets hold detailed resolutions while the parent map records condensed outcomes and the next available frontier [04:09–06:14](https://www.youtube.com/watch?v=F3lL98Pj90o&t=249s).
- **Run one bounded session per decision**: Research, prototype, grilling, and task tickets have distinct purposes; dependency relationships defer work until its prerequisites are settled [06:14–09:23](https://www.youtube.com/watch?v=F3lL98Pj90o&t=374s).
- **Convert the resolved map into delivery artifacts**: When the destination is buildable, Pocock turns the map into a specification and implementation tickets while retaining links to fuller decision context [09:23–11:08](https://www.youtube.com/watch?v=F3lL98Pj90o&t=563s).
- **Do not use the process for every task**: Pocock recommends ordinary single-session planning when the route is already understood and frames substantial uncertainty as the reason to use Wayfinder [11:08–12:08](https://www.youtube.com/watch?v=F3lL98Pj90o&t=668s).
