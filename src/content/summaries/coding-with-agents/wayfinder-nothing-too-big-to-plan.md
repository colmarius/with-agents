Matt Pocock presents Wayfinder for work whose unresolved decisions cannot fit reliably into one agent session. It stores a map in an issue tracker, exposes a frontier of currently answerable tickets, and keeps blocked questions in fog until research, prototypes, discussions, or external tasks resolve their dependencies.

### Key Points Covered

- **Plan uncertainty, not only implementation tasks**: An initial grilling session establishes the destination, then identifies decisions that need research, prototyping, further discussion, or real-world action [00:02:02]-[00:04:09].
- **Persist the route in an issue tracker**: Child tickets hold detailed resolutions while the parent map records condensed outcomes and the next available frontier [00:04:09]-[00:06:14].
- **Run one bounded session per decision**: Research, prototype, grilling, and task tickets have distinct purposes; dependency relationships defer work until its prerequisites are settled [00:06:14]-[00:09:23].
- **Convert the resolved map into delivery artifacts**: When the destination is buildable, Pocock turns the map into a specification and implementation tickets while retaining links to fuller decision context [00:09:23]-[00:11:08].
- **Do not use the process for every task**: Pocock recommends ordinary single-session planning when the route is already understood and frames substantial uncertainty as the reason to use Wayfinder [00:11:08]-[00:12:08].

The demonstration does not compare planning quality, delivery time, token cost, or defects, and it does not address stale maps, conflicting decisions, or issue-maintenance overhead.
