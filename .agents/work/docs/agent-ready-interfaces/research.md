Oracle independently ranked agent-ready interfaces first. Its rationale was
that the existing series serves workflow, proof, context, measurement, and
orchestration jobs, but not the software designer building a machine-operable
domain surface.

## Editorial boundary

The selected article is about interface and system design: composable commands,
inspectable state, faithful feedback, checkpoint/reset semantics, mutation
gates, least privilege, and human return paths. It is not a protocol tutorial,
harness comparison, parallel-agent guide, or claim that CLIs and REPLs are
universally superior. Cross-source rules are labeled as editorial synthesis.
