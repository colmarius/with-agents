# Section landing page redesign

Status: completed
Category: design
Updated: 2026-08-26

## Why

Review and redesign the Coding, Cloud, and Security landing pages so they expose
the value already in the knowledge library and never make static coverage cards
look interactive. The solution must remain useful while only Coding has posts
and Cloud and Security currently rely on reviewed resource collections.

## Summary

The shared context page now uses a content-first hierarchy: curated field guides
for Coding, curated reviewed-summary links for every context, and populated
collection routes only when they add navigation beyond the featured set. Static
checks and representative mobile/desktop browser flows pass.
