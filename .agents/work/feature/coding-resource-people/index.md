# Coding Resource People Grouping

Status: completed
Category: feature
Updated: 2026-08-29

## Why

Make the Coding with Agents resource catalog easier to browse when the same
practitioners appear across talks, interviews, demonstrations, and series.
Favor the smallest useful grouping over a generalized people taxonomy.

## Summary

Implemented and verified a collapsed, server-rendered Featured practitioners
disclosure on the main Coding with Agents catalog. It keeps the existing
catalog and navigation behavior unchanged and curates two build-validated
summary starting points for each of five practitioners.
